# Gerenciador de Gastos Residenciais

Sistema completo para controle e gestão de orçamento doméstico, permitindo o registro de despesas, categorização de gastos, geração de relatórios e acompanhamento financeiro familiar.

## Sobre o Sistema

### Funcionalidades
- **Controle de Despesas**: Registro e categorização de gastos familiares
- **Gestão de Categorias**: Organização personalizada de tipos de gastos
- **Relatórios Financeiros**: Visualização de resumos e análises mensais
- **Multi-usuários**: Suporte a diferentes membros da família
- **Dashboard Intuitivo**: Interface amigável para acompanhamento em tempo real

### Arquitetura
O sistema é dividido em duas partes principais:

#### **Backend (API)**
- Desenvolvido com .NET 8
- Banco de dados para armazenamento persistente
- API RESTful com autenticação via token JWT

#### **Frontend (Aplicação Web)**
- Desenvolvido com React.js
- Interface responsiva e moderna
- Comunicação com API via Axios
- Gerenciamento de estado com Context API
- Experiência de usuário otimizada
